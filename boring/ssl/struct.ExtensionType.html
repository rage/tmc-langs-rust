Struct ExtensionType

pub struct ExtensionType(/* private fields */);
Expand description

Extension types, to be used with ClientHello::get_extension.

WARNING: The current implementation of From is unsound, as it’s possible to create an ExtensionType that is not defined by the impl. From will be deprecated in favor of TryFrom in the next major bump of the library.
